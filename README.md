## 🚀 Quick Start

### Prerequisites
- Modern web browser
- Node.js (optional, for development server)

### Installation

1. **Clone or Download**
   ```bash
   git clone [repository-url]
   cd harshitwrites
   ```

2. **Install Dependencies** (optional)
   ```bash
   npm install
   ```

3. **Run Development Server** (optional)
   ```bash
   npm run dev
   ```

4. **Open in Browser**
   - Navigate to `index.html` in your browser
   - Or visit `http://localhost:3000` if using development server

## 🎨 Design System

### Color Palette
- **Primary**: `#2D3748` (Dark Gray)
- **Secondary**: `#4A5568` (Medium Gray)
- **Accent**: `#805AD5` (Purple)
- **Accent Light**: `#B794F4` (Light Purple)
- **Background**: `#FFFFFF` (White)
- **Background Alt**: `#F7FAFC` (Light Gray)

### Typography
- **Headings**: Playfair Display (Serif)
- **Body**: Inter (Sans-serif)
- **Hierarchy**: Clear size progression from h1 to h6

### Spacing System
- **Base Unit**: 0.5rem (8px)
- **Scale**: xs (0.5rem) → sm (1rem) → md (1.5rem) → lg (2rem) → xl (3rem) → 2xl (4rem) → 3xl (6rem)
